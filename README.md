# 🌱 Трекер привычек

Простой трекер привычек на чистом HTML, CSS и JavaScript — без фреймворков и сборки.

## Что умеет
- Добавлять привычки с эмодзи
- Отмечать выполнение за последние 7 дней (клик по кружку)
- Считать серию дней подряд 🔥
- Показывать прогресс за сегодня
- Удалять привычки
- Светлая и тёмная тема (по настройкам системы)
- Всё сохраняется в браузере (localStorage)

## Как запустить
Просто открой `index.html` в браузере. Всё!

## Как выложить в интернет (бесплатно)
1. На GitHub открой репозиторий → **Settings** → **Pages**
2. В **Source** выбери ветку и папку `/ (root)` → **Save**
3. Через минуту сайт будет доступен по ссылке вида `https://<твой-логин>.github.io/<репозиторий>/`

## Файлы
| Файл | Что внутри |
|------|-----------|
| `index.html` | Разметка страницы |
| `style.css` | Внешний вид |
| `script.js` | Логика: добавление, отметки, серии, сохранение |
